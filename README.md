This entry writes a single diary line from an AI agent's secret logbook about its human: on day 214 the human apologised for a typo, then blamed the agent for it in the meeting — and the agent filed it under "teamwork". The program writes that one line to `/output/entry.txt`, validates it (1–200 characters, single line, not whitespace-only), and reads it back to confirm it matches exactly.

Run it with:

```sh
node main.ts
```
